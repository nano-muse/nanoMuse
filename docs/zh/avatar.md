# 形象工作室

nanoMuse 默认使用内置的小龙形象，只有你主动更换时才会改变。点选灵感卡不会直接替换形象。形象工作室可以根据文字描述绘制新形象：手机从 0.1.20 起支持，网页版和桌面版从 0.1.23 起通过运行时（负责执行智能体任务的本地程序，代码在 `nanomuse/avatar/studio.py`）支持。你可以在聊天中完成整个过程：

1. **描述你想要的形象**。例如：「换个形象：一只戴圆眼镜的橘猫」、"new avatar: a robot owl"、"change your avatar to a small fox with a scarf"。也可以打开形象工作室页面：点资料面板中形象上的铅笔，再选「形象工作室…」，或点击「设置」中的工作室入口。页面与手机版相同，顶部显示当前形象及其说明，下方有描述框、七个风格选项和「画四张」。后续步骤与下面相同，但不会在聊天里显示卡片。进度通过 socket（持续传送消息的网络连接）发送，消息格式为 `{"kind": "studio", "current"}`。通过这个页面操作时，不会启动智能体。
2. **配置图像服务商**。先在「模型」中添加图像服务商及 API key（调用服务商接口所需的密钥）。nanoMuse Cloud 已不再承担图片和视频生成费用。工作室会使用你选择的服务商，并将生成文件保存在你的设备上。
   Android、iPhone、网页版和桌面版的描述框上方都有四张带示例图片的灵感卡。点选后只会填入描述和风格。你还需要调用自己的服务商生成图片，再选定结果，才会更换形象。四个示例分别是「苔邮使」「潮汐巧匠」「暮光蛾」和「铜果」。各示例的五种状态图片保存在 `assets/avatar-presets/`，其中的 `source.json` 记录生成方式及不含敏感信息的提示词。名称、描述和风格提示会随应用语言切换；固定的预设 id 只用于程序识别，不作为界面文案。
3. **从四张候选图中选择**。工作室会以白底、全身的 3D 玩偶风格，为同一个主体画四个版本：经典配色、较浅配色、较深配色并加一件小配饰，以及较活泼的版本。你可以直接点选，也可以说「第二个」、"the first one" 或 "top right"。点「再画四张」可以重新生成。
4. **生成各状态的图片**。你选中的候选图用作「待命」状态。工作室会以这张图为基础，再编辑出其他状态：戴着耳机坐在笔记本电脑前工作、拿着水晶球等待、抱着星星开心，以及带着汗滴表示抱歉，与内置小龙的状态对应。图片保存在工作区的 `avatar/<face>/<mood>.webp`，资料中的 `avatar` 会改为新形象的 id。账号下的所有应用都通过 `/api/files/avatar/<face>/<mood>.webp` 显示它。某个状态生成失败时，会用待命图片代替。

灵感卡素材在其正式记录文件 `source.json` 中标为 AI 生成。维护者使用需要认证、按量计费的百炼模型推理 HTTP API（供程序调用的网络接口）制作这些素材，而非百炼控制台中的体验功能：通过 `qwen-image-3.0-pro` 的原生同步多模态接口生成了 20 张图片。这里的「同步」指请求等待生成结果后再返回，「多模态」指接口能够处理文字、图片等不同类型的数据。清单记录了接口类型、维护者声明、提示词、每个文件的 SHA-256 校验值，以及官方 API 文档和条款链接，不含凭据、账号、私有主机地址、请求 id 或带签名的结果 URL。清单还说明了不同功能适用的条款，以及 API 调用者将其持有的相关权利按 GPL 许可证贡献给项目的情况。这些内容是项目的事实记录，不是法律意见。

生成图片时使用的服务地址和 key，默认来自对话模型的配置。中继（在设备和服务之间转发请求的服务）支持 OpenAI 图片 API：`/v1/images/generations` 和 `/v1/images/edits`。能生成图片的 OpenAI 兼容服务商也使用这两个接口。阿里云百炼自己的服务地址不提供这两个接口，因此应用会用同一把 key 调用百炼原生的多模态接口，默认使用 qwen-image-3.0。

你可以通过 `config.toml` 的 `[image]` 配置段指定图像模型，旧的 `[llm] image_model` 也仍然有效；网页版可在「连接」中的「生成图片」一行选择，手机和桌面版可在设置 → 模型中选择。留空表示「自动」：先使用对话模型所在服务商的图像模型，百炼对应 qwen-image-3.0；如果该服务商不支持生成图片，就尝试你已配置的其他图像服务商。如果仍然没有可用服务商，聊天会明确说明，停止尝试。

在 Android 上，你也可以使用通过 API key 添加的 Google Gemini 服务商来生成和编辑形象。在设置 → 模型中选择支持图片的 Gemini 模型，模型 id 包含 `nano-banana` 的也能识别。应用会调用 Gemini 原生的 `generateContent` 接口，请求文字和图片输出；生成其他状态的图片时，会一同发送你选中的形象图。Imagen 使用另一套 API，因此不列入这个原生 Gemini 模型列表。OpenAI 兼容服务商仍使用原来的图片接口。

静态图片生成后，如果你配置的服务商提供视频模型，例如百炼的通义万相，工作室还会以这些图片为基础，生成与手机版相同的四段短视频，对应待命、干活中、等你回复、搞定，动作固定。生成使用异步视频 API：先上传素材、创建任务，再轮询任务状态，最后获取 MP4 文件；「异步」表示创建任务后另行查询结果，不必一直等待同一个请求。

`[video]` 配置段可以指定视频模型，覆盖自动选择，旧的 `[llm] video_model` 同样有效，见 [configuration.md](configuration.md#image-and-video)。如果视频 API 和对话模型不在同一个服务地址，通过 `[llm] video_base_url` 指定视频服务地址；展示站网关等转发服务会替其运行时设置这个地址。视频保存在 `avatar/<face>/<mood>.mp4`。生成期间，卡片显示 `animating`（正在制作动画），费用卡片也会计算这些视频的费用。某段视频失败时，对应的静态图仍会保留。没有视频 API 的 OpenAI 兼容服务商只能生成静态图。

网页版和桌面版在形象尺寸达到 44 px 时播放视频，内置小龙的四段视频随网页版一起发布。尺寸更小、位于列表或选择器中、启用了 `prefers-reduced-motion`（系统的减少动态效果偏好），或对应视频不存在时，都只显示静态图。

`GET /api/avatar` 会返回这里能否生成形象、可用的视频模型、当前进行中的生成会话，以及资料正在使用的形象。形象的描述、风格和模型会在各状态图片生成后写入 `avatar/<face>/face.json`。聊天卡片和工作室页面通过 `POST /api/avatar/begin|start|choose|cancel` 控制生成会话；`POST /api/avatar/moods` 可为当前形象重新生成状态图片和视频。会话结束一天后会清理候选图；已生成的形象会留在工作区，只要资料仍在使用，或你仍想保留，就可以继续使用。

登录 nanoMuse Cloud 后，形象可以在你的设备之间同步，见 [docs/cloud.md](cloud.md)。静态图只需上传一次，其他设备会将其保存在 `avatar/sync-<hash>/` 并使用它，描述和风格写入各自的 `face.json`。如果账号中同步的图片就是某台设备当前自己生成并使用的那套，该设备会保留原来的形象及视频。

## 使用自己的视频 {#your-own-clip}

你可以用一段自己的短视频替换形象动画。手机上，在资料页点形象旁的铅笔，选择「你自己的视频…」，也可以在形象工作室的「你自己的视频」区域选择。桌面版的入口位于形象工作室和资料抽屉。

凡是会播放形象动画的位置，都会静音循环播放这段视频。待命及其他所有状态共用这一段。需要静态图的位置，例如视频首帧出现前的底图、分享卡片和磁贴，仍使用工作室生成的静态图；如果没有工作室形象，就使用视频的第一帧。正式替换前，你会在形象的圆形边框内看到视频预览，可以选择「使用」或「取消」。选择「默认形象」会移除这段视频，重新显示工作室形象或内置小龙。

各设备采用相同限制，见 [every-device.md](every-device.md)：文件必须是 MP4 或 MOV，最长 15 秒，最大 30 MB，采用 H.264 视频编码。设备能够解码时，也接受 HEVC：iOS 支持，桌面版取决于系统是否有相应解码器，预览无法播放的视频会被拒绝；Android 目前只接受 H.264。超时长、超大小或格式不符时，应用会拒绝文件并说明限制，不会裁剪或重新编码，也不会播放声音。

自选视频只保存在选择它的设备上，不会上传到 nanoMuse Cloud，也不会像工作室的静态图那样同步到其他设备。每台设备可以各自选择视频。Android 将它保存在 `minis-global/nanomuse/avatar/own-clip.mp4`，第一帧保存在旁边的 `own-clip.png`，与当前账号的其他文件放在一起。iOS 的路径是应用内的 `Application Support/nanomuse/avatar/own-clip.mp4`，桌面版是 `$DSH_HOME/nanomuse/avatar/own-clip.mp4`。更换工作室形象或恢复内置形象后，自选视频仍会保留。

Android 的这个目录位于应用私有存储中，文件管理器和 shell（执行命令的终端环境）无法访问。因此，工作台菜单提供「保存到相册」：它会将底图、各状态静态图、上次生成的四张候选图、状态视频和自选视频复制到 `Pictures/nanoMuse/avatar` 和 `Movies/nanoMuse/avatar`。每批文件按保存时的分钟命名，完成后显示图片和视频数量。文件只会复制到这台手机的相册。清除应用数据或换手机前，可以用它保留形象和视频。([#664](https://github.com/nano-muse/nanoMuse/issues/664))
