# nanoMuse 品牌规范 {#nanomuse-品牌}

本规范于 2026-09-24 确定。App 图标和界面配色采用同一套设计：界面的颜色取自图标，使 App 内外的视觉风格保持一致。

本页的设计变量（design token）是颜色等样式的统一名称，例如 `primary`。SVG 是可以无损缩放的矢量图格式，PNG 则是由像素组成的位图。

## 标志 {#the-mark}

标志由一条连续笔画构成，整体像字母 **N**。笔画从带钩的起点出发，经过一个圆弧形的峰顶、一条长斜线和一个收紧的谷底，最后向上收笔。整个图形只有一个拱形，设计上更接近连贯的书写动作，而不是规整的印刷字母。

- 原始文件是 `assets/brand/nanomuse-icon-source-1024.png`，内容为品牌蓝背景上的白色圆角方块。这是最终渲染图，其他资源都由它派生。
- `assets/brand/nanomuse-mark.svg` 只包含标志笔画。笔画转换为一条带渐变填充的路径，`viewBox` 为 `0 0 100 100`，使用图标方块的坐标系。`viewBox` 定义 SVG 内部坐标的范围。
- `assets/brand/nanomuse-icon.svg` 将白色圆角方块（`rx=27`）与标志组合，作为 App 图标。`rx` 是圆角半径。
- `assets/brand/nanomuse-icon-on-blue.svg` 是带品牌蓝背景的版本，仅用于应用商店页面和启动画面。README、网站、社交分享卡片、favicon（浏览器标签页上的小图标）等代表 App 身份的地方，都使用白色方块、标志和细边框的版本，不加蓝色背景。
- `assets/brand/nanomuse-mark-rgba-688.png` 是宽 688 px、带透明通道的笔画位图，用于无法使用矢量图的场景。px 表示像素。
- `docs/app-icon.png` 是 512 px 的图标成品：圆角半径为边长的 27 %，方块外透明，并带有 `#D9D9DE` 细边框，保证放在白色背景上也能看清轮廓。README 的头图，以及将 nanoMuse 作为 App 展示的地方，都使用这张图。

App 图标与聊天形象用途不同。默认聊天形象是随附的小龙，资源位于 `web/public/avatars/` 和 Android App 的 `avatar/` 中。用户也可以选择带底色的 emoji，或在形象工作室生成自己的形象。早期使用的小熊猫已于 0.1.23 移除。

不要把小龙或旧版小熊猫用作启动器图标，也不要把 N 标志用作聊天形象。

## 颜色 {#colour}

以下颜色从图标中测得。

| 设计变量 | 值 | 用途 |
|---|---|---|
| `brand.stroke.start` | `#015CFB` | 标志渐变的起始颜色，位于左端 |
| `brand.stroke.end` | `#0186FB` | 标志渐变的结束颜色，位于右端 |
| `brand.blue` | `#0078FD` | 图标方块背后的背景色，以及启动画面和头图的背景色 |
| `tile` | `#FFFFFF` | 图标的白色方块 |

### 浅色主题 {#light-theme}

| 设计变量 | 值 | 对比度 | 用途 |
|---|---|---|---|
| `primary` | `#015CFB` | 白色背景上为 5.35 | 链接、带白色文字的主按钮、状态行 |
| `primary.container` | `#E5F0FF` | — | 选中行、标签 |
| `ink` | `#000000` | 白色背景上为 21 | 用户消息气泡配白字；发送和「回到最新」圆形按钮配白色箭头；当前标签的圆形底色 |
| `pill` | `#F2F2F7` |  | 智能体的消息气泡 |
| `primary.tint` | `#EEF5FF` | — | 需要轻微突出显示的区域 |
| `bg` | `#FFFFFF` |  | 聊天背景、底部胶囊栏、菜单和抽屉面板 |
| `bg.grouped` | `#F2F2F7` | — | 设置页面，保留 OpenMinis 原有配色 |
| `surface` | `#FFFFFF` | — | 卡片和输入框 |

对比度表示前景与背景在亮度上的差异。数值越大，通常越容易分辨；这里的数值均对应表中指定的背景色。

### 深色主题 {#dark-theme}

| 设计变量 | 值 | 对比度 | 用途 |
|---|---|---|---|
| `primary` | `#58A6FF` | 在 `#000` 上为 8.3，在 `#1C1C1E` 上为 6.7 | 链接、带黑色文字的按钮、状态行 |
| `primary.container` | `#1A2B4A` | — | 选中行、标签 |
| `ink` | `#FFFFFF` | 在 `#000` 上为 21 | 用户消息气泡配黑字；发送和「回到最新」圆形按钮配黑色箭头；当前标签的圆形底色 |
| `pill` | `#1C1C1E` |  | 智能体的消息气泡 |
| `bg` / `surface` / `surface.2` | `#000000` / `#1C1C1E` / `#2C2C2E` | — | 保留 OpenMinis 原有配色 |

界面只使用一种强调色。OpenMinis 原来分别用 iOS 蓝、橙、绿显示的代码块、思考文字和链接，统一改用 `primary` 和中性色。

对话区域以黑白灰为主。用户消息气泡、发送按钮和当前标签使用 `ink`；蓝色只用于链接和状态行。Android 的对应定义在 `ChatColors.kt` 中，由 `scripts/rebrand.py` 生成。小龙自身的颜色只用于形象，不作为界面配色。

## Android 中的对应实现（S1 已完成） {#android-mapping-done-in-s1}

- 自适应图标由三层组成：背景层为纯白 `#FFFFFF`；前景层为标志，使用 `VectorDrawable`，其 `fillColor` 为上述两个色标构成的线性渐变；单色层使用相同路径和纯色填充，由 Android 根据主题着色。自适应图标是可适配不同启动器裁切形状的 Android 图标。
- 图标外观沿用 OpenMinis 的 activity 别名机制，即用不同启动入口显示不同图标。「自动」和「浅色」使用白色方块；「深色」使用 `#0F1B33` 方块和白色标志。
- 通知栏小图标使用纯白标志，尺寸为 24 dp。dp 是 Android 按屏幕密度换算的界面尺寸单位。
- 发布时不得包含旧的 OpenMinis 图标、名称或字母 n 版图标草稿。

## 使用限制 {#don-ts}

- 标志只能使用蓝色渐变、纯白或纯黑。
- 不要旋转标志、添加描边或给笔画加阴影。
- 标志放在品牌蓝背景上时，必须保留白色方块，以保证对比度。
- 不要使用其他产品的标志、名称或品牌蓝作为素材，只使用 nanoMuse 自己的标志。
